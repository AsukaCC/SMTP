# BunMail RS 0.2.0

- 仅保留首次初始化创建的单个管理员，移除普通账号、注册入口和注册开关。
- 移除密码找回接口、页面及服务器密码重置命令。
- 服务设置支持手动检查 GitHub 正式版本，不在启动时或每 6 小时自动检查。
- Docker 受管安装可启用宿主机更新服务，在后台下载并校验构建包、备份数据库和加密密钥、安装更新、检查健康状态并显示进度。同迁移指纹下失败会回退，保留当前和上一版本。
- 更新管理界面样式，支持简体中文、英文和手机布局。

## 安装包

根据服务器架构下载 `bunmail-rs-0.2.0-linux-amd64.tar.gz` 或 `bunmail-rs-0.2.0-linux-arm64.tar.gz`，使用 `SHA256SUMS` 校验后解压。包内包含 Docker 镜像和安装工具；首次安装仍需联网拉取 PostgreSQL 镜像。GitHub 自动提供的 Source code 压缩包不是安装包。

安装及后台更新服务启用步骤见仓库的 `docs/releases.zh-CN.md`。应用容器无需挂载 Docker socket；后台安装须先由服务器管理员启用宿主机更新服务，只点击检查更新不会自动安装。

## 从旧版迁移

本版本新增数据库迁移，保留管理员、邮件、模板及队列，删除普通账号及其会话，移除验证和找回密码令牌。升级前必须备份 PostgreSQL 数据库与原 `.env`（包含私钥加密密钥），并验证备份可恢复。

`0.1.0` 与本版本迁移指纹不同，受管工具会拒绝直接更新或自动回退。已有实例须单独制定和验证数据迁移、恢复流程；不能删除数据卷重新安装，也不能仅换回旧镜像作为数据库回退。

## 验证

发布流程在 Linux amd64、arm64 原生环境从源码构建，验证首次安装、后台更新、手动回退、故障自动回退、两版本保留、数据保留及数据库备份恢复，通过 Rust、Python 和数据库集成检查后发布附件。模拟 SMTP 测试不代表已验证真实公网投递。
