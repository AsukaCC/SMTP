# BunMail RS 0.2.1

- 使用本地打包的 `liquid-glass-react` 重构登录页、浮动导航、卡片及弹窗，支持简体中文、英文、明暗主题和手机布局，并提供高对比度、减少动态与透明效果的适配。
- 在“服务设置 → 管理员密码”增加密码重设：验证当前密码后设置新密码，保存后撤销全部管理员会话，所有设备需重新登录。接口仅允许管理员同源会话访问，具有限流和并发修改保护。
- 优化密码框：显示／隐藏切换、保持光标位置、大写锁定提示，以及新密码长度、差异与确认提示。
- Docker 构建从源码生成前端资源，运行时无需 Node.js 或外部 CDN。GitHub 更新检查仍仅由管理员手动触发。

## 安装与更新

按服务器架构下载 `bunmail-rs-0.2.1-linux-amd64.tar.gz` 或 `bunmail-rs-0.2.1-linux-arm64.tar.gz`，使用 `SHA256SUMS` 校验后解压。安装包包含 Docker 应用镜像及受管部署工具，首次安装仍需联网拉取 PostgreSQL 镜像。

本版本数据库迁移指纹与 `0.2.0` 相同。已启用宿主机更新服务的 Docker 受管安装，可在后台手动检查并安装；更新前自动备份 PostgreSQL 与 `.env`（含加密密钥），健康检查失败时自动回退。保留当前及上一版本，邮件队列和数据卷保留。步骤见 [版本更新与回退文档](https://github.com/AsukaCC/SMTP/blob/v0.2.1/docs/releases.zh-CN.md)。

`0.1.0` 实例与本版本迁移指纹不同，须先备份并单独制定、验证数据迁移和恢复流程，受管工具会拒绝直接跨迁移指纹更新。密码重设入口要求已经登录并提供当前密码。

## 验证

本地已验证 Rust 格式、Clippy、单元测试、独立数据库集成测试、Python 测试，以及中英文、明暗主题、1440/390/320px 布局和实际密码重设及会话撤销流程。发布流程在 Linux amd64、arm64 原生环境构建，并验证安装、更新、手动回退、故障自动回退、两版本保留、数据保留和数据库备份恢复后发布附件。模拟 SMTP 测试不代表已验证真实公网投递。
